## 1. 车辆/行人检测与跟踪

### 1.1 UA-DETRAC

| 项目 | 说明 |
|------|------|
| **全称** | UA-DETRAC (University at Albany Detection and Tracking) |
| **规模** | 100 个交通视频序列，超过 140,000 帧，约 8,250 个车辆实例（检测集 10,900 张标注图片，4 类：car, bus, van, others） |
| **标注内容** | 车辆边界框(bounding box)、车辆类别、遮挡标注、天气标注、截断标注 |
| **场景** | 城市道路、高速公路等多种交通场景，晴天/阴天/雨天等多种天气条件 |
| **获取方式** | 官网下载：https://detrac-db.rit.albany.edu/ ；Kaggle 上也有镜像 |
| **许可证** | 学术研究免费，商用需联系授权 |
| **项目对应关系** | **视频结构化感知层 - 目标检测模块**：用于训练和评估车辆检测模型（YOLO/DETR 等），覆盖多天气多场景的交通监控画面；**单摄轨迹生成层**：用于评估 ByteTrack/BoT-SORT 等多目标跟踪算法在交通场景下的性能 |

### 1.2 MOT17

| 项目 | 说明 |
|------|------|
| **全称** | MOT Challenge 2017 |
| **规模** | 7 个训练视频序列 + 7 个测试视频序列，每个序列提供 3 种检测器（DPM/FRCNN/SDP）的检测结果，分辨率 1920x1080，总帧数约 12,600 帧（训练集） |
| **标注内容** | 行人边界框、跟踪 ID、可见度比例、目标类别（行人为主） |
| **场景** | 公共场所行人场景，包含拥挤、遮挡等挑战 |
| **获取方式** | 官网注册下载：https://motchallenge.net/data/MOT17/ |
| **许可证** | 学术免费（CC BY-NC-SA 4.0），需注册账号 |
| **项目对应关系** | **单摄轨迹生成层**：用于训练和评估多目标跟踪算法（ByteTrack/BoT-SORT/DeepSORT/OC-SORT），尤其关注跟踪中的 ID 切换和遮挡处理能力。虽然以行人为主，但跟踪算法框架可直接迁移到车辆跟踪 |

### 1.3 MOT20

| 项目 | 说明 |
|------|------|
| **全称** | MOT Challenge 2020 |
| **规模** | 4 个训练视频序列 + 4 个测试视频序列，单帧最多 246 人，高分辨率 |
| **标注内容** | 行人边界框、跟踪 ID、可见度比例 |
| **场景** | 极高密度人群场景，比 MOT17 更具挑战性 |
| **获取方式** | 官网注册下载：https://motchallenge.net/data/MOT20/ |
| **许可证** | 学术免费（CC BY-NC-SA 4.0），需注册账号 |
| **项目对应关系** | **单摄轨迹生成层**：用于评估跟踪算法在极端拥挤条件下的鲁棒性，验证算法在高密度交通场景（如路口人流/车流密集时）的跟踪性能 |

### 1.4 KITTI

| 项目 | 说明 |
|------|------|
| **全称** | KITTI Vision Benchmark Suite |
| **规模** | 目标检测：7,481 张训练图 + 7,518 张测试图；目标跟踪：21 个训练序列 + 29 个测试序列（共约 15,000 帧）；总计约 80,000+ 个标注目标 |
| **标注内容** | 2D/3D 边界框、车辆类别（Car, Van, Truck, Pedestrian, Cyclist 等）、遮挡级别、截断比例、深度信息、LiDAR 点云 |
| **场景** | 德国卡尔斯鲁厄城市道路、乡村公路、高速公路，车载前视视角 |
| **获取方式** | 官网注册下载：http://www.cvlibs.net/datasets/kitti/ |
| **许可证** | CC BY-NC-SA 3.0（学术免费，非商用） |
| **项目对应关系** | **视频结构化感知层 - 目标检测**：用于训练和评估车辆/行人检测模型，特别是 2D 检测器；其跟踪子集可用于验证单摄跟踪算法在车载场景下的性能 |

### 1.5 BDD100K

| 项目 | 说明 |
|------|------|
| **全称** | BDD100K: A Large-scale Diverse Driving Video Database |
| **规模** | 100,000 段高清视频（每段约 40 秒，720p, 30fps），采样 100,000 张关键帧图片（1280x720）；目标检测标注约 1,400,000 个框；多目标跟踪标注约 1,400 个视频段 |
| **标注内容** | 8 类目标边界框（person, rider, car, truck, bus, train, motorcycle, bicycle）、语义分割、实例分割、车道线标注、多目标跟踪 ID |
| **场景** | 美国多个城市，覆盖不同地理位置、天气条件（晴/雨/雪/雾）、时间段（白天/夜晚），场景多样性极高 |
| **获取方式** | 官网注册下载：https://bdd-data.berkeley.edu/ ；论文：arXiv:1811.12231 |
| **许可证** | BSD 3-Clause License（允许学术和商业使用） |
| **项目对应关系** | **视频结构化感知层 - 目标检测 + 跟踪**：最大规模的公开驾驶数据集之一，8 类目标覆盖项目所需的车辆、行人、非机动车等全部类别；多天气多时段数据可增强模型泛化能力；MOT 标注可直接用于训练单摄跟踪算法；**属性识别**：丰富的场景多样性有助于训练鲁棒的属性识别模型 |

### 1.6 Cityscapes

| 项目 | 说明 |
|------|------|
| **全称** | The Cityscapes Dataset |
| **规模** | 50 个德国城市的街景图片；精细标注 5,000 张 + 粗略标注 20,000 张 + 无标注训练额外 19,998 张；图片分辨率 2048x1024 |
| **标注内容** | 30+ 类语义分割标注（含 car, truck, bus, person, rider 等）、实例分割标注、像素级精细标注 |
| **场景** | 欧洲城市街景，多种天气和光照条件 |
| **获取方式** | 官网注册下载（需 .edu 邮箱）：https://www.cityscapes-dataset.com/ |
| **许可证** | 自定义学术许可（非商用，需署名），需教育邮箱注册 |
| **项目对应关系** | **视频结构化感知层 - 目标检测/语义分割**：高质量的城市场景像素级标注可用于训练精细的场景理解模型，辅助目标检测和属性识别；覆盖 car, truck, bus, person 等关键类别 |

## 2. 车辆 ReID / 行人 ReID

### 2.1 VeRi-776

| 项目 | 说明 |
|------|------|
| **全称** | VeRi-776 (Vehicle Re-Identification 776) |
| **规模** | 50,000+ 张图片，776 个车辆 ID，20 个摄像头，24 小时连续采集，覆盖 1.0 平方公里区域 |
| **标注内容** | 车辆边界框、车辆 ID、车辆类型、车辆颜色、车辆品牌、车牌边界框、车牌字符串、车辆时间戳、相邻摄像头距离、约 9,000 条车辆轨迹 |
| **场景** | 真实城市交通监控场景，多视角（2~18 个视角/车）、多光照、多遮挡 |
| **获取方式** | GitHub 论文附带数据：https://github.com/JDAI-CV/VeRi-776 ；OpenDataLab 镜像：https://opendatalab.org.cn/OpenDataLab/VeRi-776 |
| **许可证** | 学术研究免费 |
| **项目对应关系** | **跨镜轨迹拼接层 - 车辆 ReID 模块**：最经典的车辆 ReID 基准之一，包含车牌标注和时空信息，与项目中"融合车牌一致性+ReID 外观相似度+时空可达性"的跨镜拼接策略高度吻合；可直接用于训练和评估车辆 ReID 特征提取模型 |

### 2.2 VehicleID (PKU VehicleID)

| 项目 | 说明 |
|------|------|
| **全称** | PKU VehicleID |
| **规模** | 221,763 张图片，26,267 个车辆 ID；其中 10,319 辆车（90,196 张图片）标注了详细车型信息 |
| **标注内容** | 车辆 ID、车辆型号（如 "MINI-cooper"、"Audi A6L"、"BMW 1 Series"） |
| **场景** | 中国某小城市，多个真实监控摄像头，白天采集 |
| **获取方式** | 官网：https://pkuml.org/resources/pku-vehicleid.html ；OpenDataLab：https://opendatalab.org.cn/OpenDataLab/VehicleID |
| **许可证** | 学术免费，非商用 |
| **项目对应关系** | **跨镜轨迹拼接层 - 车辆 ReID + 属性识别**：大规模车辆 ID（26K+）适合训练高泛化能力的 ReID 模型；车型标注可用于训练车型分类器，辅助跨镜拼接中的"属性一致性"评分；中国城市场景与项目目标场景（苏州相城区）高度相似 |

### 2.3 VERI-Wild

| 项目 | 说明 |
|------|------|
| **全称** | VERI-Wild: A Large Dataset and a New Method for Vehicle Re-Identification in the Wild |
| **规模** | 416,314 张图片，40,671 个车辆 ID，174 个训练摄像头 + 100 个测试摄像头，覆盖超过 200 平方公里市区，24 小时连续拍摄 30 天 |
| **标注内容** | 车辆 ID、摄像头 ID、时间戳、摄像头间跟踪关系、车辆颜色、车辆类型、车辆品牌、辅助属性 |
| **场景** | 城市道路、交通灯区域、交叉口、高速收费站、匝道入口等，覆盖雾天/雨天/晴天等多种天气，白天和夜间均有 |
| **获取方式** | GitHub：https://github.com/PKU-IMREAL/VERI-Wild |
| **许可证** | 学术研究免费 |
| **项目对应关系** | **跨镜轨迹拼接层 - 车辆 ReID**：最大规模的车辆 ReID 公开数据集之一，40K+ 车辆 ID 和 174+ 摄像头规模可训练高鲁棒性 ReID 模型；包含摄像头 ID 和时间戳，与项目中"摄像头拓扑+时空可达性+ReID 外观"的跨镜拼接框架直接对应；多天气多时段特性可增强模型在实际部署中的鲁棒性 |

### 2.4 Market-1501

| **项目对应关系** | **跨镜轨迹拼接层 - 行人 ReID**：行人 ReID 领域最经典的基准数据集之一，用于训练和评估行人 ReID 特征提取模型；项目第二阶段（行人/非机动车扩展）的核心训练数据 |

### 2.6 MSMT17

| 项目 | 说明 |

## 3. 车牌识别 (OCR)

### 3.1 CCPD (Chinese City Parking Dataset)

| 项目 | 说明 |
|------|------|
| **全称** | CCPD (Chinese City Parking Dataset) |
| **规模** | CCPD 2019：超过 300,000 张图像（蓝色普通车牌）；CCPD 2020 (CCPD-Green)：新能源车牌（绿色八位车牌）；总计超过 250,000 个独特车牌图像，图像分辨率 720x1160 |
| **标注内容** | 车牌号码（编码在文件名中）、车牌边界框、四个顶点坐标、倾斜角度（水平/垂直）、亮度、模糊度等；9 个子集：CCPD-Base, CCPD-DB(双车牌), CCPD-Blur(模糊), CCPD-FN(远距离), CCPD-Rotate(旋转), CCPD-Tilt(倾斜), CCPD-Challenge(挑战), CCPD-NP(无车牌), CCPD-Weather(天气) |
| **场景** | 中国某省会城市（合肥）所有街道的路边停车场，手持 POS 机拍摄，各种光照/角度/天气条件 |
| **获取方式** | GitHub：https://github.com/detectRecog/CCPD ；OpenDataLab：https://opendatalab.org.cn/OpenDataLab/CCPD ；HuggingFace 镜像可用 |
| **许可证** | Apache 2.0 License |
| **项目对应关系** | **视频结构化感知层 - 车牌 OCR 模块**：最核心的中文车牌数据集，300K+ 图像覆盖各种复杂条件（模糊/倾斜/远距离/天气变化），直接用于训练车牌检测模型和车牌字符识别模型；9 个子集可针对性地增强模型在各类困难条件下的鲁棒性；CCPD 2020 覆盖新能源车牌，符合当前车辆趋势 |

### 3.2 CRPD (Chinese Road Plate Dataset)

| 项目 | 说明 |
|------|------|
| **全称** | CRPD (Chinese Road Plate Dataset) |
| **规模** | 包含 3 个子集：CRPD-single（单层车牌）、CRPD-double（双层车牌）、CRPD-multi（多车牌场景） |
| **标注内容** | 车牌号、车牌边界框、四个顶点坐标、车牌类型（蓝牌/绿牌/黄牌/白牌等） |
| **场景** | 道路场景，多种拍摄角度和光照条件，覆盖黑/蓝/绿/白/黄五种车牌颜色 |
| **获取方式** | 无官方统一下载入口，可通过 GitHub 上的 CCPD+CRPD 合并仓库获取：https://github.com/zeusees/CCPD ；部分第三方平台有整理版本 |
| **许可证** | 学术免费 |
| **项目对应关系** | **视频结构化感知层 - 车牌 OCR 模块**：补充 CCPD 的道路场景数据，特别是双层车牌（大型车辆后牌）和多车牌场景；五种颜色车牌覆盖项目实际部署中可能遇到的所有中国车牌类型；与 CCPD 联合训练可提升车牌识别模型的泛化能力 |

## 4. 图文跨模态检索

### 4.1 MS-COCO

| 项目 | 说明 |
|------|------|
| **全称** | Microsoft Common Objects in Context (MS-COCO) |
| **规模** | 330,000+ 张图片，其中 123,287 张有 5 条人工英文注释（共约 820,000 条 caption）；标准检索分割：训练 113,287 张 / 验证 5,000 张 / 测试 5,000 张 |
| **标注内容** | 图文对（image-caption pairs）、目标检测框（80 类）、关键点、语义分割、全景分割 |
| **场景** | 日常生活场景，涵盖人物、动物、交通工具、家具等多种目标 |

## 5. 路网拓扑与地图数据

### 5.1 OpenStreetMap (OSM)

| 项目 | 说明 |
|------|------|
| **全称** | OpenStreetMap |
| **规模** | 全球覆盖的开源地理数据库，包含道路、建筑、水体等空间信息；苏州市相城区可通过区域查询获取完整路网数据 |
| **标注内容** | 道路中心线（way）、道路名称、道路等级（highway=motorway/trunk/primary/secondary/residential 等）、车道方向、车道数、限速、交叉口节点（node）、道路拓扑关系 |
| **场景** | 全球城市/乡村道路网络，苏州市相城区数据覆盖城区主要道路和支路 |
| **获取方式** | **方式一 - Overpass API**：通过 https://overpass-api.de/ 使用查询语句提取苏州市相城区路网（先查城市 relation ID，再按 area-query 提取 highway 类型 way）；**方式二 - OSMnx (Python)**：`ox.graph_from_place("相城区, 苏州市, 江苏省", network_type='drive')` 直接获取路网图结构；**方式三 - Geofabrik**：https://download.geofabrik.de/asia/china.html 下载中国 .osm.pbf 后用 osmium 裁剪；**方式四 - Overpass Turbo**：https://overpass-turbo.eu/ 交互式查询导出 GeoJSON |
| **许可证** | ODbL (Open Database License)：自由使用、修改和分享，需署名 OpenStreetMap 贡献者 |
| **项目对应关系** | **视频接入与数据治理层 + 跨镜轨迹拼接层**：(1) 提取苏州市相城区路网拓扑，构建摄像头之间的拓扑可达性关系；(2) 计算摄像头之间的道路距离，用于估计合理旅行时间范围（如"40~150 秒"约束）；(3) 获取道路方向信息，过滤逆向或不合理连接；(4) 获取摄像头经纬度坐标用于地图轨迹展示；(5) 推断段候选路径生成：两个摄像头之间的多条可能道路对应多条候选路径及置信度 |

#### 苏州市相城区路网提取示例流程

```
步骤1: 查询苏州市 relation ID
  Overpass API 查询: <has-kv k="name:zh" v="苏州市"/>
  得到苏州市 ID（如 3020001）

步骤2: 提取相城区路网
  使用 OSMnx:
  import osmnx as ox
  G = ox.graph_from_place("相城区, 苏州市, 江苏省, 中国", network_type='drive')

步骤3: 提取道路属性
  - highway 类型 -> 道路等级
  - oneway -> 单行道方向
  - lanes -> 车道数
  - name -> 道路名称
  - maxspeed -> 限速

步骤4: 计算摄像头间最短路径和旅行时间
  - 基于路网图的最短路径算法
  - 结合限速估算合理旅行时间范围
```
